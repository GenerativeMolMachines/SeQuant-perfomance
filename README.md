# SeQuant-perfomance

This repository contains the necessary resources and code for training and evaluating models described in our work. Below, we provide a detailed description of the repository structure and its components.

## Data

The data directory contains all datasets required for training models and conducting predictions on benchmark datasets. The folder hierarchy is described below.

### learning

This folder includes three datasets: small_test_df.csv and small_train_df.csv, which were used to train all autoencoder models described in this study, and energy_data.csv, which contains data on amino acid interaction energies with cations of certain divalent metals. These data are used as descriptors (note that the descriptor set is not limited to these features; additional features are calculated using the RDKit library). The original data for energy_data.csv were obtained from Hu X. et al. (2022) [https://doi.org/10.1038/s41597-022-01297-3]. 

The training datasets were formed by parsing sequences from the NCBI database [https://www.ncbi.nlm.nih.gov/]. Both small_test_df.csv and small_train_df.csv contain two columns:
- sequence: amino acid sequences.
- cluster: cluster labels obtained via k-means clustering of one-hot peptide sequences. These labels are essential for contrastive learning.

### benchmark

This folder contains datasets used for benchmarking the embeddings generated by the SeQuant model. 

To evaluate the performance of the proposed approach in supervised learning tasks, several publicly available benchmark datasets were selected for peptide classification tasks, including:
- Prediction of peptides with antimicrobial activity [https://doi.org/10.1093/bib/bbad058].
- Prediction of peptides with anti-inflammatory activity [https://doi.org/10.1021/acs.jcim.3c01563].
- Prediction of peptides with antidiabetic activity [https://doi.org/10.7717/peerj.13581].
- Prediction of peptides with antioxidative activity [https://doi.org/10.1016/j.compbiomed.2023.106591].

Additionally, for regression tasks, the test dataset small_test_df.csv (referred to here as regression) was used. 

The first four datasets include the following columns:
- seq: peptide sequences.
- label: corresponding activity labels (1 or 0).

The regression dataset only contains the column seq, as the physicochemical property values are computed in the code (see the **Benchmarking** section) using the Peptides library [https://pypi.org/project/peptides/].

### embeddings_SeQuant

This folder contains embeddings generated by the cBiLSTM-AE model in the format [dataset_name]_[encoding].csv, where encoding = 'sequant'. These embeddings are necessary for benchmarking since we do not provide a pre-trained model. Additionally, due to anonymity requirements during double-blind review, we cannot provide a link to the API used to access the model.

## Models

The models directory contains all models developed as part of this work. It includes five subfolders named after the architectures used (CAE stands for convolutional autoencoder, VAE - variational autoencoder, cBiLSTM - BiLSTM autoencoder with contrastive learning). Each subfolder contains:
- learning.py: Code for training the model.
- preset_tools.py: A file with utility functions required for training.
- A file defining the model architecture.

## Processing

The processing directory contains a single .py file that implements the preprocessing pipeline for datasets located in data/benchmark. This pipeline generates all encodings and embeddings investigated in this study, including one-hot, blosum62, threemers encodings, ProtBERT embeddings, and SeQuant embeddings.

Due to double-blind review requirements, the SeQuant API section is unavailable as it relies on a resource link that cannot be shared at this stage. To reproduce our results, please comment out this section in the code. All necessary SeQuant embeddings are provided in the data/embeddings_SeQuant directory. For proper execution, move these embeddings to the data/encoded folder.


## Benchmarking

The main directory contains a Jupyter Notebook file (benchmarking.ipynb) that details the benchmarking process for all embeddings and encodings across each dataset using 5-fold cross-validation.
