# SeQuant-performance

This repository contains the necessary resources and code for training and evaluating models described in our work [future link].

The repository provides:

- Training code for all autoencoder-based models investigated in the study;
- Scripts for generating peptide embeddings;
- Benchmark datasets;
- Benchmarking pipeline for downstream classification and regression tasks.

Note that pre-trained SeQuant models are not distributed. To reproduce the results, users must train the model and generate embeddings following the instructions below.

## Data

The data directory contains all datasets required for training models and conducting predictions on benchmark datasets. The folder hierarchy is described below.

### learning

This folder includes 5 datasets: small_test_df.csv and small_train_df.csv, which were used to train all autoencoder models described in this study, energy_data.csv, which contains data on amino acid interaction energies with cations of certain divalent metals. These data are used as descriptors (note that the descriptor set is not limited to these features; additional features are calculated using the RDKit library). The original data for energy_data.csv were obtained from Hu X. et al. (2022) [https://doi.org/10.1038/s41597-022-01297-3]. Finally, medium_test_df.csv and medium_train_df.csv datasets were used for scaling experiment.

The training datasets were formed by parsing sequences from the NCBI database [https://www.ncbi.nlm.nih.gov/]. Both small_test_df.csv and small_train_df.csv contain two columns:
- sequence: amino acid sequences.
- cluster: cluster labels obtained via k-means clustering of one-hot peptide sequences. These labels are essential for contrastive learning.

### benchmark

This folder contains datasets used for benchmarking the embeddings generated by the SeQuant model. 

To evaluate the performance of the proposed approach in supervised learning tasks, several publicly available benchmark datasets were selected, including:
- Prediction of peptides with antimicrobial activity [https://doi.org/10.1093/bib/bbad058];
- Prediction of peptides with anti-inflammatory activity [https://doi.org/10.1021/acs.jcim.3c01563];
- Prediction of peptides with antidiabetic activity [https://doi.org/10.7717/peerj.13581];
- Prediction of peptides with antioxidative activity [https://doi.org/10.1016/j.compbiomed.2023.106591];
- Prediction of peptides with hemolytic activity [https://doi.org/10.1021/acs.jpclett.3c02398];
- Prediction of nonfouling peptides [https://doi.org/10.1021/acs.jpclett.3c02398];
- Prediction of soluble peptides [https://doi.org/10.1021/acs.jpclett.3c02398];
- Prediction of MIC of peptides against E. Coli [https://huggingface.co/datasets/jiahuizhang/PepBenchData].


### embeddings_SeQuant

This folder contains embeddings generated by the dcBiLSTM-AE model in the format [dataset_name]_[encoding].csv, where encoding = 'sequant'. Pre-trained SeQuant models are not distributed. Therefore, benchmark embeddings generated by the dcBiLSTM-AE model are provided for reproducibility purposes.

## Models

The models directory contains several subfolders corresponding to the architectures evaluated in this study:
 - CAE stands for convolutional autoencoder;
 - CVAE - convolutional variational autoencoder;
 - BiLSTM - baseline BiLSTM autoencoder;
 - cBiLSTM - BiLSTM autoencoder with contrastive learning;
 - dcBiLSTM - diagonalized BiLSTM autoencoder with contrastive learning (**main model used in the study**);
 - transformer - simple transformer-based autoencoder.


Each subfolder contains:
- learning.py: Code for training the model;
- preset_tools.py: A file with utility functions required for training;
- A file defining the model architecture.

The Models directory also contains a subfolder named PeptideCLM. It contains the files required to reproduce benchmarking experiments involving the PeptideCLM model [https://github.com/AaronFeller/PeptideCLM].

## Processing

The processing directory contains files that implement the preprocessing pipeline for datasets located in `data/benchmark`. This pipeline generates all encodings and embeddings investigated in this study.



## Benchmarking

The main directory contains a .py file (benchmarking.py) that details the benchmarking process for all embeddings and encodings across each dataset using 5-fold cross-validation. 


## Installation

### Requirements

- Python 3.10
- CUDA-compatible GPU (recommended)

### Create environment

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

Then install dependencies:

```bash
pip install -r requirements.txt
```


## Reproducing Results

The benchmarking workflow consists of three stages.

### Step 1. Train a model

Example:

```bash
python models/dcBiLSTM/learning.py
```

This step produces a trained model checkpoint.

### Step 2. Generate embeddings

```bash
python processing/compute_embeddings.py
```

Embeddings will be saved into: `data/embeddings_SeQuant/`

### Step 3. Run benchmarking

```bash
python benchmarking.py
```

This script performs 5-fold cross-validation on all benchmark datasets and reports classification and regression metrics.
